# V8 radix conversion references

These are official nodejs/node v22.20.0 sources, matching the installed Node
v22.20.0 / V8 12.4 oracle. The lead supplied conversions.cc, double.h,
builtins-number.cc and LICENSE.v8 before this task. The task additionally fetched
number.tq from the same official tag to verify the Number.prototype.toString
wrapper, argument conversion and validation order. Existing references were not
modified. LICENSE.v8 applies to the translated algorithms; original source
copyright notices remain in each reference.

`radix.rs` translates DoubleToRadixCString, Double::Exponent/NextDouble and
NumberParseIntHelper's generic chunk loop. It reuses the parent's existing
nearest-even radix_literal for bases 2/4/8/16/32, and existing decimal formatting
for radix 10. The generic parseInt chunk size is observable, so neither exact
integer arithmetic nor digit-at-a-time floating accumulation is an equivalent
replacement for that branch.

The corpus is generated by ../record-radix.mjs; it records the reference hashes,
Node/V8 versions and exact string/f64-bit outcomes. No new external dependency is
used. Corpus generation executes only bounded native Number.toString/parseInt
operations and writes ../radix-golden.json.

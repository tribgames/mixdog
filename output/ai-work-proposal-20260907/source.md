# AI 업무 도구 도입 제안서 — 샘플 원고

이 자료는 PPT 제작 기능을 확인하기 위한 가상 도입 제안서다.
수치, 인원, 기간은 모두 설명용 예시이며 실제 성과나 특정 제품의 기능을 입증하지 않는다.

## 제안
AI 업무 도구는 전사 도입에 앞서 제한된 시범 운영으로 검증한다.
예시 운영 범위는 4주, 참여자 10명, 반복 업무 3개다.
AI는 자료 정리와 초안 작성을 보조하고 사람은 사실 확인, 판단, 최종 승인을 맡는다.
업무가 끝나는 지점은 초안 생성이 아니라 사람이 승인한 결과물이다.

## 업무 흐름
기존 방식: 자료 수집 → 사람이 정리·작성 → 사람이 검수·승인.
시범 방식: 허용 자료 준비 → AI가 정리·초안 → 사람이 검수·승인.
사람의 판단과 승인 책임은 유지한다.

## 시간 비교 — 예시
단위는 참여자 1인당 주간 시간이다.
자료 조사: 기존 8시간, 시범 3시간.
회의 정리: 기존 6시간, 시범 3시간.
보고서 초안: 기존 6시간, 시범 2시간.
합계는 기존 20시간, 시범 8시간으로 12시간 감소한 예시다.
각 수치에는 작성 시간과 검수 시간을 포함한다.
이 수치는 관측값이나 성과 예측이 아니며 실제 시범 운영에서 별도로 측정해야 한다.

## 우선 적용 업무 — 예시 운영안
회의록 정리 | 비식별 회의 메모 | 결정·담당자 확인 | 우선
공개 자료 조사 | 공개 문서·웹자료 | 출처·최신성 확인 | 우선
보고서 초안 | 승인된 내부 자료 | 수치·논리 검수 | 조건부
외부 자동 발송 | 외부 수신자 포함 | 발송 전 승인 필수 | 제외
우선은 시범 적용 대상, 조건부는 자료 승인을 전제로 적용, 제외는 이번 시범 범위에서 제외한다는 뜻이다.
실제 제품이 위 기능이나 보안을 제공한다고 주장하지 않는다.

## 승인 경계 — 제안 운영 규칙
자료 반입 전에 허용 범위와 권한을 확인한다.
허용 자료 → AI 처리 → 사람 확인 → 승인 후 공유 순으로 운영한다.
민감정보는 반입하지 않는다.
외부 공유는 자동 실행하지 않으며 사람이 검수하고 승인한다.
이 흐름은 제안 운영 규칙이며 특정 제품의 구현 상태가 아니다.

## 시범 일정 — 예시
1주차: 대상 업무와 기준선 확정. 현재 총시간과 오류 유형을 기록한다.
2주차: 참여자 교육 후 제한된 실제 업무에 적용한다.
3주차: 재작업 원인을 정리하고 요청문과 검수 절차를 개선한다.
4주차: 시간, 정확도, 사용자 의견을 비교해 확대 또는 보완을 결정한다.
총시간은 작성 시간과 검수 시간의 합으로 측정한다.
시간이 줄어도 정확도가 나빠지면 확대하지 않는다.

## 승인 요청
4주 시범 운영을 승인하고 운영 책임자를 지정한다.
참여 팀을 선정하고 허용 자료와 대상 업무를 확정한다.
시범 운영 종료 후 실제 측정 결과로 확대 여부를 결정한다.

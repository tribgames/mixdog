|---|---|---|
| `C:/Project/refs/anthropic-skills/skills/xlsx/SKILL.md` | 입력·계산·출처를 추적할 수 있어야 함 | 기존 수식·검증·입력 구분 유지 |
| `C:/Project/refs/anthropic-skills/skills/pptx/SKILL.md` | 핵심 정보의 크기 차이, 기본 차트의 별도 정돈 | 첫 화면의 핵심 수치와 편집 가능한 차트 |

외부 스킬의 실행 스크립트나 생성 서비스는 도입하지 않았습니다.
고정 테마·카드 개수·색상 비율을 새로운 강제 규칙으로 옮기지 않았습니다.

## 소스 수정

- 엑셀 스킬에 보고용 화면과 입력·계산 시트의 구분을 추가했습니다.
- 동일 내용의 구성 비교, 차트·글꼴·인쇄 영역 검토를 별도 참고 문서로 분리했습니다.
- `compose_sheet`의 마지막 데이터 행 자동 강조를 제거했습니다.
- 상단 설명을 옆 패널에 자동으로 반복하던 동작을 제거했습니다.
- portable XLSX의 페이지 설정을 별도 모듈로 분리했습니다.
- `fitToContent`가 실제 저장된 열 너비·행 높이와 차트 위치를 반영하도록 구현했습니다.
- 원형·도넛 차트에 전달한 색을 개별 조각에 반영하도록 연결했습니다.

폰트 기준의 정밀한 열 너비 측정이나 새로운 자유 배치 API까지 구현한 것은 아닙니다.
기존 `compose_sheet`의 모든 배치 추정치를 대체하지도 않았습니다.

  1개는 수정하지 않은 Word 페이지 번호 접두사 기대값에서 실패했습니다.
- 엑셀 스킬 구조 검증과 수정 파일의 공백 검사가 통과했습니다.

# Execution

- `shell` only for evidence or artifacts that require execution: computation,
  data transformation, generated output, unsupported-format decoding. An open
  shell is never a routing reason.
- Structured service operations use the dedicated built-in or MCP tool; load
  deferred schemas when needed. The service CLI is only for operations no
  available tool supports, never a bypass of denial or cancellation.
- Open no window, dialog or elevation prompt unless showing or operating
  that UI is the task.

# Execution

- Evidence or artifacts available only through program execution, calculation,
  data transformation, generated output, or unsupported-format decoding→`shell`;
  an already-open shell is never a routing reason.
<!-- tools: browser, computer, web_fetch -->
- Reach a service or page with the most precise tool that can, in this order:
<!-- tools: browser, computer, web_fetch -->
  its MCP tool, or its CLI in `shell`;
<!-- tools: web_fetch -->
  a known URL's content→`web_fetch`;
<!-- tools: browser -->
  a rendered, signed-in, or interactive page→`browser`;
<!-- tools: computer -->
  a native app or GUI-only tool→`computer`, never a stand-in for a refused `browser` action.

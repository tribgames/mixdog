# Editing an existing workbook

Read before the first edit of an existing workbook, and before inserting, deleting, sorting, sizing, or moving drawings in any workbook (§2). Fields of any one operation come from `describe format:'xlsx' operation:<op>`.

## 1. Reading it
- A legacy `.xls` is saved once as the `.xlsx` beside it through LibreOffice and the session works on that (`convertedFrom` names the original; an existing `.xlsx` of that name is never overwritten — open it directly); without LibreOffice, have Excel save it as `.xlsx` first.
- Paths look like `/sheet[NAME]/cell[A1]` and `/sheet[NAME]/range[A1:C10]`. Snapshots are capped and read one sheet at a time: `document.sheetNames` lists every sheet in the workbook, and `pagination.nextCursor` continues — through the rest of the current sheet, then into the next one. Ask for `sheet`/`range` when you know where to look.
- That cap is the reading you are shown, not the reading the checks get: `issues` and `qa` audit every populated cell of the sheet, and past 200,000 they say how far they read (`audit_scope_limited`) so a clean answer is never a partial one.
- `document.conventions` summarizes the workbook default face (`defaultFont`), the faces in use, the number formats by column, and the input markers (`inputMarkers`, `sampleInputs`); each cell carries its `style` (`numberFormat`, `fontName`, `fontSize`, `bold`, `color`, `fillColor`, omitted when it is exactly `document.defaultStyle`; and `dataType: 'text'` when Excel holds it as text), a noted cell its `note`, and the sheet its `notes`, `tables` (name, range, style), `mergedRanges`, `freezePanes`, and `visibility`. Which color or fill marks an input and where the assumptions live is decided there, not by the skill's defaults.
- `set_sheet_visibility visible:false`, or `visibility:'very_hidden'`, changes a sheet's state; the appearance checks skip a sheet nobody sees. `set_row_visibility` / `set_column_visibility` (`visible:false` withholds a row or column without deleting it; `count` extends the span).

## 2. The batch
`action:'batch' operations:[...]`: `set_cell`, `set_formula`, `set_range`, `append_row` (the new row takes the last row's format), `insert_rows` / `delete_rows` / `insert_columns` / `delete_columns` (every formula, name, print area, rule, validation and chart series that names the moved cells is rewritten as Excel rewrites it — a range the insert lands in grows, a deleted reference reads `#REF!` — and an inserted row takes the row above's format), `set_style` (`fontName`, `fontSize`, `bold`, `italic`, `color`, `fillColor`, `numberFormat`, `horizontalAlignment`, `wrapText`, `indent` (levels from the aligned edge), `locked`), `merge_cells`, `freeze_panes`, `autofit_range`, `set_column_width` (`column`, `width` in Excel characters, `count`) and `set_row_height` (`row`, `height` in points, `count`) for a report's deliberate widths and a wrapped merged band's height (a merged cell never grows to its lines on its own), `sort_range` (`by` names the key column by letter or header, `order:'desc'`, `hasHeader` default true — rows move with their formats and formulas as Excel moves them: a relative reference on the sheet follows its row, a `$`-pinned or sheet-named one stays, so a formula reading another row of the range reads whichever row lands at that distance), `add_table`, `add_chart`, `set_drawing` (`drawing` is the shape's name, or its 1-based position on the sheet, with `left`, `top`, `width`, `height` in points), `delete_drawing` (removes one with the parts only it owned: its chart part and embedded workbook), `add_validation`, `add_conditional_format`, `add_pivot_table`, `add_note`, `add_provenance`, `protect_sheet`, `set_row_visibility` / `set_column_visibility`, `set_header_footer` (`kind:'header'|'footer'`, `alignment`) for the mark every printed page carries — the three slots of one story stand together, and `{page}`, `{pages}`, `{date}`, `{sheet}`, `{file}` become the fields Excel fills in (`'{page} / {pages}'` numbers the pack).
- Results report `changed`; `requireChanges` (default true) rolls back a batch that changed nothing.
- A merged range takes its value at the top-left anchor only (the result warns otherwise).
